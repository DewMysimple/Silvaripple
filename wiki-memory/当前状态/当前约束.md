# 当前约束

## 技术约束

- Windows 桌面应用，当前验证目标为微信 `4.1.12.50`。
- 保持 Python 数据核心、React/Vite 前端、Tauri 2 桌面壳和稳定 RPC Bridge；数据核心不做破坏式重写。
- 生产构建必须离线运行，用户无需安装 Python、Node 或 Rust。
- 数据根自动发现必须有限、只读；手动目录必须经布局验证，禁止持久化构建机器路径。
- 会话、预览、选择、统计和可见任务历史必须跟随当前账号上下文。

## 安全约束

- 微信数据库、WAL 和 SHM 始终只读，禁止注入、修改微信进程或提取登录凭据。
- 明文快照只存在临时目录，导出失败或取消时清理半成品。
- 日志、设置、历史和工程记忆不得保存正文、内部账号标识、密钥、Token 或完整媒体地址。

## 质量约束

- 保持 Bridge 合约兼容，重构通过门面渐进完成。
- 每个逻辑变更必须通过 Python、React、TypeScript、格式检查、浏览器回归、Rust/Tauri、记忆体检和本地交付验证。
- 不把构建产物、运行时二进制或用户数据提交进仓库。

## 交付约束

- 每个完整逻辑任务直接提交并推送 `origin/main`。
- 根 `dist/` 只保留最新 `ChatWechat.zip` 与对应解压 `ChatWechat/`；完整应用包含 sidecar 和离线运行时，直接运行解压目录的主程序验收。
- 发布前检查候选 ZIP，异常时整组回滚；不覆盖应用目录内未知用户文件。GitHub Release 只有用户明确要求时创建。
