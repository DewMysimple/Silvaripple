# 当前约束

## 技术约束

- Windows 桌面应用，当前验证目标为微信 `4.1.12.50`。
- 保持 Python 后端、React 静态前端和 pywebview Bridge；不做破坏式重写。
- 生产构建必须离线运行，用户无需安装 Python 或 Node。

## 安全约束

- 微信数据库、WAL 和 SHM 始终只读，禁止注入、修改微信进程或提取登录凭据。
- 明文快照只存在临时目录，导出失败或取消时清理半成品。
- 日志、设置、历史和工程记忆不得保存正文、内部账号标识、密钥、Token 或完整媒体地址。

## 质量约束

- 保持 Bridge 合约兼容，重构通过门面渐进完成。
- 每个逻辑变更必须通过相关测试、记忆体检和本地发布验证。
- 不把构建产物、运行时二进制或用户数据提交进仓库。

## 交付约束

- 每个完整逻辑任务直接提交并推送 `origin/main`。
- 本地源码包和 NSIS 安装包固定覆盖到被 Git 忽略的 `artifacts/发布版本/`；PyInstaller onedir 只存在于系统临时 staging，GitHub Release 只有用户明确要求时创建。
