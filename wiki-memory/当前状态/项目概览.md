# 项目概览

## 项目目标

ChatWechat 是 Windows 本地微信手动导出工作台。它在用户主动操作时只读解析微信 4.x 本地数据，提供会话浏览、搜索、媒体检查、统计和 HTML、Markdown、JSON 归档。

## 当前阶段

核心读取、预览、导出和 React 工作台已经可用；当前进入模块化维护、可复现 EXE 打包和正式发布流程建设阶段。

## 主要使用者

- 本机已登录微信账号的数据所有者。
- 维护 Python、React 和 Windows 打包流程的工程 Agent。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `chatwechat/` | Python 领域逻辑、数据库、媒体、导出和桌面服务 |
| `frontend/` | React 19、TypeScript、Vite 前端源码 |
| `tests/` | 不读取真实聊天正文的 Python 回归测试 |
| `wiki-memory/` | Agent 工程记忆、决策、知识和日志 |
| `artifacts/发布版本/` | 被 Git 忽略的本地 NSIS 安装包和校验文件 |
| `artifacts/安装版/ChatWechat/` | 被 Git 忽略的、由 NSIS 更新的工程内安装实例 |

## 重要入口

- 源码启动：`python -m chatwechat`
- 前端构建：`frontend/package.json`
- 桌面 Bridge：`chatwechat/service.py`
- 测试：`python -m pytest`
