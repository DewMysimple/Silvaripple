# 项目概览

## 项目目标

ChatWechat 是 Windows 本地微信手动导出工作台。它在用户主动操作时只读解析微信 4.x 本地数据，提供会话浏览、搜索、媒体检查、统计和 HTML、Markdown、JSON 归档。

## 当前阶段

核心读取、预览、导出和 React 工作台已经可用；Tauri 2 桌面壳支持自动/手动数据发现与多账号上下文隔离。工作台统一排版并按功能模块拆分，交付为根 dist 中的应用 ZIP 与对应解压目录。

## 主要使用者

- 本机已登录微信账号的数据所有者。
- 维护 Python、React 和 Windows 打包流程的工程 Agent。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `chatwechat/` | Python 领域逻辑、数据库、媒体、导出和 sidecar 服务 |
| `frontend/` | React 19、TypeScript、Vite 前端和 `src-tauri` Rust 桌面壳 |
| `tests/` | 不读取真实聊天正文的 Python 回归测试 |
| `wiki-memory/` | Agent 工程记忆、决策、知识和日志 |
| `dist/ChatWechat.zip` | 被 Git 忽略的最新应用压缩包 |
| `dist/ChatWechat/` | 从同一 ZIP 解压的应用，直接运行 ChatWechat.exe 验收 |

## 重要入口

- 源码启动：`python -m chatwechat`（启动 Tauri 开发窗口）
- 前端构建：`frontend/package.json`
- Tauri 壳：`frontend/src-tauri/src/lib.rs`
- Python RPC：`chatwechat/sidecar.py`、`chatwechat/desktop/bridge.py`
- 测试：`python -m pytest`
