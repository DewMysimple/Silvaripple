# 2026-08-23｜桌面运行时与分层入口

- 目标：建立源码与冻结态共用的桌面入口、资源定位和管理员授权子模式。
- 状态：完成。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- `pyproject.toml` 是应用版本唯一来源。
- 同一个桌面入口按参数分发 UI、授权助手和无界面自检。
- 运行组件优先查找便携目录，源码态再回退系统 PATH。

## 文件变更

- 新增 Desktop、Application、Domain、Infrastructure 和 Export 分层入口。
- Bridge 从应用服务文件移入 Desktop 适配层，并保留旧导入兼容。
- 媒体转换统一通过运行资源定位器获取 Node 和 FFmpeg。
- 冻结态授权改为 `ChatWechat.exe --authorize-helper`。

## 测试与验证

- Python 73 项测试通过。
- 源码 `--self-test --json` 验证网页、WASM、运行组件、WebView2、CNG 和 DPAPI。

## 待确认长期记忆

- 无；本阶段实现遵循既有 active 架构决策。
