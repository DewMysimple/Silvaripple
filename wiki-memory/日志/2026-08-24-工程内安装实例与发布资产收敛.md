# 2026-08-24｜工程内安装实例与发布资产收敛

## 目标

- 根据用户确认，停止生成源码 ZIP，并让所有本地产物留在工程内。
- 在发布安装包之外，保留一个由同一 NSIS 安装流程更新的工程内安装实例，便于直接启动和验证。

## 决策

- `artifacts/发布版本/` 只保留 NSIS 安装包和 SHA-256 清单。
- `artifacts/安装版/ChatWechat/` 作为当前工程内安装实例，使用 NSIS 测试安装器更新，包含 `ChatWechat.exe` 和卸载程序。
- GitHub Release 只发布安装包和校验文件；GitHub 仓库承担源码分发，不再额外打包源码。
- 发布失败时工程内旧安装实例通过同目录备份恢复，避免半成品替换。

## 变更

- `Publish-Local.ps1` 移除源码归档步骤，增加工程内安装实例的安全替换、自检和结果字段。
- `Build-Installer.ps1` 返回无快捷方式测试安装器路径，供本地安装实例使用。
- Release 工作流移除源码 ZIP 组装和上传。
- README、当前状态、构建知识和 ADR-007 同步新的资产边界；ADR-006 的产物部分标记为 superseded。

## 验证

- 运行 Python、React、TypeScript 和前端生产构建检查。
- 运行 NSIS 构建、自检、隔离安装/卸载以及工程内安装实例自检。
- 核对 Git 忽略规则，确保安装包和安装实例不进入提交；核对工程外不再产生发布产物。

## 遗留

- 首版仍未提供代码签名，Windows 可能显示未知发布者。
- 工程内安装实例是本机验证/直接运行副本，正式用户安装仍以 NSIS 安装包为准。
