# ADR-002｜模块化桌面单体架构

## 决策

保留 Python、React、pywebview 组合，采用 Desktop、Application、Domain、Infrastructure、Export/Media 和 Frontend 功能切片。现有 Bridge 与 `ChatWechatService` 作为兼容门面，内部渐进委托。

## 理由

- 当前技术栈已经覆盖核心能力，重写不会直接改善用户价值。
- 稳定门面允许拆分大型文件而不同时改动所有调用方。

## 验证

- Bridge 合约、Python 回归测试、前端类型检查和便携版自检全部通过。
