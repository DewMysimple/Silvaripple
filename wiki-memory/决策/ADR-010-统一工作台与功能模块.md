# ADR-010｜统一工作台与功能模块

## 决策

- `App.tsx` 只装配外壳与页面；`features/` 按首页、会话、搜索、导出、媒体、任务、设置划分，各功能拥有视图、动作 hook、模型及样式。
- 跨页面行为和视觉放入公共层：`ui/` 提供布局与交互原语，`features/accounts/DataSourcePicker` 复用首次连接和设置中的目录工作流，`utils/labels` 统一消息类型文案。
- `state/` 分开账号、会话、操作切片；账号与数据根成功改变时由同一上下文重置函数清理账号数据，异步回写核对上下文代次。
- 样式从统一主题/字体/间距 token 出发，公共控件不能在功能页面复制；正文与辅助字号随字体偏好缩放。重排修改原规则，不叠加长期覆盖补丁。
- 视觉基底保持中性：浅色使用白画布、浅灰分区与黑灰文字，深色保持中性灰。品牌绿色仅用于少量操作、勾选、焦点与状态，不用于大面积渐变或给普通背景、边框和文字整体染色。
- 高密度信息先展示摘要，详情、筛选和高级配置按需展开；主要操作保持清晰，页面必须验证窄桌面、宽屏、深色及大字体。

## 验证

行为测试验证业务约束和异步边界；浏览器测试验证跨页面真实交互及布局；类型检查拒绝未用符号，Prettier 保持格式一致。不要以硬编码组件行数、文案或 CSS 字符串替代行为验证。
