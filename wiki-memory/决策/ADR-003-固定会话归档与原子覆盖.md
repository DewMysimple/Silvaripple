# ADR-003｜固定会话归档与原子覆盖

## 决策

导出不创建时间批次根目录。会话按设置布局写入固定目录，并通过稳定、不可逆归档标识识别同一账号下的同一会话。再次导出完整替换旧会话目录。

展示名称使用微信资料原昵称，不使用本地备注；内部追溯字段只保留在 JSON。

## 安全保证

- 新版本先写临时目录，提交失败或文件占用时回滚。
- 不能验证为 ChatWechat 归档的同名目录绝不覆盖。
- 旧历史不得删除已由后续任务更新的会话目录。
