# ADR-006｜工程内产物与源码入口

## 决策

- 根目录不保留 `.pyw` 启动脚本，源码入口固定为 `python -m chatwechat`。
- PyInstaller 使用 `chatwechat/desktop/frozen_entry.py` 作为包内冻结入口。
- 本地安装包、源码 ZIP 和 SHA-256 清单统一输出到被 Git 忽略的 `artifacts/发布版本/`。
- 不再生成或交付免安装便携版；构建 staging 只存在于系统临时目录。
- 现有桌面便携版按用户确认彻底清理，微信数据、用户配置和既有导出归档不在清理范围。

## 维护边界

- Git 只保存源码、测试、构建脚本、配置和工程记忆，不保存二进制发布产物。
- `Publish-Local.ps1` 只能在质量检查通过且工作区干净时覆盖 `artifacts/发布版本/`。
