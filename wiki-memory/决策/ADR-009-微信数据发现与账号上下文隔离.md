# ADR-009｜微信数据发现与账号上下文隔离

## 决策

- 首次启动不得携带或依赖构建机器的数据路径。
- 自动发现按只读、有限范围策略检查：已保存位置、微信当前用户注册表中的路径型设置、Windows 实际文档目录、OneDrive 文档、AppData 兼容位置、用户目录和本地固定磁盘的标准微信目录。
- 用户可手动选择 `xwechat_files`、`WeChat Files` 或单个账号目录；后端必须先验证数据库布局，再归一化并保存账号容器目录。
- 设置保存自动/手动目录模式。手动目录失效时不得静默切换到其他数据源；界面应展示候选目录并允许恢复自动发现。
- 当前账号在全局顶部切换。会话、预览、选择、统计、页面局部状态和可见任务记录必须随账号切换；任务历史按账号标识过滤。

## 安全边界

- 自动发现不递归扫描整块磁盘，不读取聊天正文，不把实际路径写入日志或工程记忆。
- 数据根校验只检查目录形状和数据库文件存在性，实际数据库读取仍使用只读快照。

## 验证

- 合成目录覆盖账号目录、数据根和父目录三种选择形态。
- 自动候选去重、注册表路径过滤、RPC 状态复用和账号历史隔离测试通过。
