# ADR-007｜工程内安装实例与发布资产

## 决策

- GitHub 仓库是源码唯一分发来源；本地发布不再生成或保留 `ChatWechat-source.zip`。
- 发布资产全部位于仓库内的被 Git 忽略目录：
  - `artifacts/发布版本/ChatWechat-Setup.exe`
  - `artifacts/发布版本/SHA256SUMS.txt`
  - `artifacts/安装版/ChatWechat/`
- `artifacts/安装版/ChatWechat/` 由同一 NSIS 测试安装器在本地更新，包含可直接运行的安装后程序文件和卸载程序，作为工程内的当前验证实例。
- 正式用户仍通过 `ChatWechat-Setup.exe` 安装到 `%LOCALAPPDATA%\Programs\ChatWechat`；工程内安装实例不替代用户安装路径。
- 旧安装实例先以同目录备份名保护，新的安装、自检全部成功后才删除旧备份；失败时恢复旧实例。

## 维护边界

- `Publish-Local.ps1` 只在测试通过且工作区干净时覆盖上述三类本地产物。
- 源码、配置、测试、构建脚本和工程记忆进入 Git；安装包、安装实例、运行时二进制和用户数据不进入 Git。
- GitHub Release 只上传版本化 NSIS 安装包及其 SHA-256 清单；不上传源码 ZIP。
