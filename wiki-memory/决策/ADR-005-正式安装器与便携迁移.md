# ADR-005｜正式安装器与便携迁移

## 决策

- 保留 Python 解密/导出后端、React 前端和 pywebview Bridge；不为安装器重写微信核心。
- 使用 NSIS 生成当前用户安装包，默认安装到 `%LOCALAPPDATA%/Programs/ChatWechat`。
- 设置、DPAPI 密钥、任务历史、缓存和临时数据继续位于 `%LOCALAPPDATA%/ChatWechat`，安装/卸载不删除用户数据和导出目录。
- PyInstaller onedir 只存在于系统临时构建 staging；本地交付固定覆盖工程内被忽略的 `artifacts/发布版本/` 安装包和源码包。
- 安装器升级前提示关闭运行中的 ChatWechat；安装失败不替换旧版本。
- 首次安装成功后，验证旧便携目录并将其重命名为带时间戳的备份目录；失败时保留原目录。
- 首版安装包不签名，提供 SHA-256；后续有证书时再增加签名步骤。

## 维护边界

- NSIS 脚本只负责安装、升级、快捷方式、卸载和旧便携目录归档。
- 微信数据读取、密钥保存和导出行为仍由 Python 应用层负责，安装器不得访问微信数据库。
