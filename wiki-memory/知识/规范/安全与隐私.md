# 安全与隐私规范

- 测试和构建不得读取真实聊天正文。
- 不提交 `%LOCALAPPDATA%` 配置、DPAPI 密文、数据库快照、导出归档或运行日志。
- 日志只记录稳定错误码和脱敏摘要。
- 下载客户端不携带 Cookie、Authorization 或微信登录凭据。
- 删除或回收操作必须验证精确目标，禁止作用于微信数据根、输出根或仓库根。
