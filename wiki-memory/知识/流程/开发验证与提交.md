# 开发、验证与提交

每个逻辑任务遵循：读取记忆 → 修改 → 测试 → 前端生产构建 → 记忆同步 → 记忆体检 → 本地发布 → 自检 → 提交并推送。

如果打包或自检失败，保留上一版外部产物，不推送失败状态。远端前进或推送冲突时停止，不执行强推。

基础命令：

```text
scripts/Invoke-QualityGate.ps1
scripts/Build-Portable.ps1
scripts/Publish-Local.ps1
```

前端命令必须使用项目锁定的 pnpm 版本。正式本地发布以已提交的 `HEAD` 创建源码包，
因此工作区存在未提交修改时发布脚本应拒绝执行。
