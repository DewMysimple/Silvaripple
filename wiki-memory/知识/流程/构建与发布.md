# 构建与发布

## 本地构建

- PyInstaller 使用 onedir/windowed 模式。
- 所有中间文件位于仓库外的临时目录。
- 便携版捆绑网页资源、silk-wasm、Node、FFmpeg 和许可证。
- Node 与 FFmpeg 的版本、文件大小和 SHA-256 由运行时锁约束；二进制不进入 Git。
- 构建先进入 staging，自检通过后才替换固定目标。
- `Build-Portable.ps1` 只构建，`Publish-Local.ps1` 要求干净工作区并原子替换外部固定产物。
- 冻结自检必须确认服务可初始化，且 Node 与 FFmpeg 来自便携目录而不是系统 PATH。

## GitHub 发布

- 日常 `main` 推送只保存源码。
- 用户明确要求发布时才更新语义版本并推送版本标签。
- 标签工作流构建版本化源码 ZIP、Windows 便携 ZIP 和 SHA-256 文件。
- 标签必须与项目唯一版本源一致；锁定 FFmpeg 归档变量缺失或校验不符时停止发布。
- 旧 Release 保留。
