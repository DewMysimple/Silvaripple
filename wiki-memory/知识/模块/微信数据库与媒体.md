# 微信数据库与媒体

## 数据库

- WCDB/SQLCipher 数据库通过 salt、页 HMAC 和 Windows CNG AES 解密。
- 微信运行时先复制数据库与完整提交范围内的 WAL，再读取解密快照。
- schema 使用字段探测适配，未知消息保留结构化原始信息。

## 媒体

- 本地缓存优先，随后才按用户导出配置尝试受限腾讯地址。
- 图片支持真实文件头、微信 V2、WXGF 等恢复路径。
- 语音通过随包 silk-wasm 与受控 JavaScript 运行时转换为 WAV。
- 所有外部媒体结果必须验证；失败原因以稳定错误码记录。

## 常见陷阱

- 扩展名不能证明真实媒体格式。
- MD5 相同或模糊文件名不能替代资源关系验证。
- 私有 CDN 标识不等于可直接下载的公开 URL。
